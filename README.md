# Supplementary Code

Code accompanying:

**Evolutionary dynamics of enlarged sex chromosomes and novel pseudoautosomal regions in Sylvioidea songbirds**

**Author:** Hanna Sigeman

Scripts are organized according to the corresponding Methods subsections in the manuscript. Each directory contains the code used to reproduce the analyses described below.

## Workflow overview

| Step | Description |
|--------|--------|
| [1. Identification of PAR genes](01_identification_of_PAR_genes/) | Annotation lift-over and PAR gene identification |
| [2. Extracting sex-specific PAR gene sequences](02_extracting_PAR_sequences/) | Read mapping, variant calling and consensus sequence generation |
| [3. PAR gene tree analyses](03_PAR_gene_trees/) | Alignments, phylogenies and Z–W divergence estimates |
| [4. Fusion, fission and PAR boundaries](04_fusion_fission_PAR_boundaries/) | Identification of sex-linked regions and chromosomal breakpoints |
| [5. Plotting and statistics](05_plotting_and_statistics/) | Figure generation and statistical analyses |
